# Website analytics

When adding or editing a public page on the main plasticcheese.com site,
check its HTML head for the Google tag. Add the tag from the root
`index.html` if it is missing. Use measurement ID `G-4G1C3TXDKX` and
verify that the page loads and configures it exactly once.

Keep the existing TinyTracker tag on pages under `tinytracker/`.
TunnelBash uses its own Analytics property on `tb.plasticcheese.com`.
